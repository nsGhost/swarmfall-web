# Swarmfall: web playtest build

**Play: https://nsghost.github.io/swarmfall-web/**

A playtest build of Swarmfall, a portrait arcade shooter, exported from Unity 6 (WebGL) for testing on phones.
Open the link on your phone; add it to your home screen for a full-screen experience.

- Drag anywhere to steer; the ship fires while your finger is down.
- Desktop: arrow keys / A–D to move, Space to fire, P or Esc to pause.
- Progress (cores, hangar, best scores) is saved in this browser.
